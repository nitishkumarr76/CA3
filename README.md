# Student Management App

A simple Android application built using **Kotlin and Jetpack Compose**.

### Features
- Add students
- View student records
- Delete students
- Local data storage using Room Database

### Technologies
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Room Database
- StateFlow
- Kotlin Coroutines
